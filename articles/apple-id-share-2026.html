一、海外 Apple ID 共享背景与注意事项

因 App Store 的区域网络政策差异，许多网络工具与代理客户端（如 Shadowrocket 小火箭、sing-box、Quantumult X 等）无法在大陆区 App Store 直接搜索和下载。为了方便广大 iOS 用户快速获取所需客户端，机场Fog 团队整理并维护了最新可用的外区公共 Apple ID 共享账号。

共享账号适合临时下载免费应用或已购应用使用。在使用前，请务必仔细阅读防锁机守则，切勿随意更改账号配置，以免造成不必要的设备异常。

⚠️ 核心安全警告（违反可能导致手机变砖）

1. 严禁在【设置 (Settings)】或【iCloud】中登录共享账号！
共享账号仅用于在 App Store（应用商店） 登录下载应用。如果误登录到手机设置中，一旦账号被苹果安全机制锁定或他人修改密码，你的设备将面临无法解绑 iCloud 甚至触发激活锁变成“板砖”的风险。

2. 下载完成后请立即退出登录！
公共账号多人共享，随时可能因异地登录触发验证。下载完所需应用后，请第一时间在 App Store 底部退出共享 ID，换回你的个人主账号。

三、安全登录 App Store 下载应用（防锁机避坑铁律）

请按以下标准化步骤进行切换登录：

  • 步骤 1：打开 App Store 并退出原账号
    打开 iPhone 或 iPad 上的 App Store，点击右上方个人头像图标。滑动到最下方点击 “退出登录 (Sign Out)”。
  • 步骤 2：登录共享海外 Apple ID
    在顶部账户名与密码框中，粘贴上方提供的共享账号与密码，点击 “登录 (Sign In)”。
  • 步骤 3：跳过双重认证绑定（关键）
    如果登录时弹出“Apple ID 安全”或“开启双重认证”提示，千万不要点击继续绑定你自己的手机号！ 请选择 “其他选项” -> “不升级” 即可跳过设置。
  • 步骤 4：搜索下载应用并及时登出
    商店页面切换后，即可搜索并下载所需的出海应用（如 sing-box、Shadowrocket 等）。下载完毕后，再次点击 App Store 右上角头像拉到底部选择退出登录，恢复你自己的个人账号。

四、常见问题排障与个人独享账号注册建议

Q1: 为什么提示“账号已被锁定/禁用”？
公共共享账号同一时间内登录人数较多，或部分用户操作不当触发苹果风控。遇到此类提示请换一个备用账号，或稍后再试。

Q2: 已经安装的 App 无法更新怎么办？
iOS 应用更新需校验原下载账号。使用共享 ID 下载的应用若需更新，建议卸载原 App 后重新使用当前可用的共享 ID 重新下载。
